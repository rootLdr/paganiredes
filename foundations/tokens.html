Fundamentos · Tokens

Tokens estruturais

Espaçamento, raios, sombras, movimento, grid e dimensões. A regra do sistema: nada uniforme por preguiça — raio, sombra e espaço variam por função.

Espaçamento — base 4

Escala racional em múltiplos de 4/8px. Ritmo vertical apoiado nela.

space-1 4px
space-2 8px

Raios — por função

xs · 2px
imagens, tags
sm · 4px
cards, badges
md · 6px
botões, inputs
lg · 10px
modais, popovers

--radius-pill (999px) reservado para o botão do WhatsApp e pills de status.

Sombras — discretas

xs · separação
sm · card elevado
md · menu/dropdown
lg · modal

Sombras curtas e de baixa opacidade — nada de “nuvem” difusa e artificial.

Movimento

Durações: fast 120ms · base 180ms · slow 240ms. Curva padrão cubic-bezier(.2,0,0,1). Animação comunica mudança de estado, não decora.

Respeita prefers-reduced-motion (durações caem para ~0).

Grid & dimensões
  • Container: 1200px (máx.) · leitura 760px.
  • Colunas: 12 (desktop) · 8 (tablet) · 4 (mobile). Gap 24px.
  • Breakpoints: 480 · 768 · 1024 · 1280.
  • Altura de campo/botão: 44px · toque mínimo 44×44.

Consumo — CSS Custom Properties

Componentes consomem tokens semânticos, nunca valores crus.

.btn-primary {
  height: var(--button-height-md);
  padding: 0 var(--space-5);
  border-radius: var(--radius-md);
  background: var(--color-interactive);
  color: var(--color-text-on-brand);
  font: var(--fw-semibold) var(--fs-sm)/1 var(--font-body);
  transition: background var(--dur-base) var(--ease-standard);
}
.btn-primary:hover  { background: var(--color-interactive-hover); }
.btn-primary:focus-visible { outline: none; box-shadow: var(--focus-ring); }

Arquivo-fonte: tokens.css — inclui as duas matrizes de tema.
